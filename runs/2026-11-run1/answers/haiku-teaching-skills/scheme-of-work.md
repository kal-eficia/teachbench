# Year 8 Computing: Python programming basics (6-week half-term)

**Assumptions:** 12 lessons (2 per week, 50 minutes each). Pupils have used Scratch in Year 7 and have not typed code. Lessons run in a browser-based Python editor the school already has access to. No exam board is named, so objectives follow general KS3 programming language. Assessment is in the final week (Lesson 12).

**Design logic:** One new idea per lesson. Every lesson starts with a retrieval starter that draws on earlier lessons. There is a mini-checkpoint in its own lesson (not with new content), a flex lesson for catch-up, and a final assessment.

## Assessment calendar
- **Week 6, Lesson 12:** End-of-unit typed assessment (50 minutes). No new content is introduced in this lesson.
- **Week 5, Lesson 10:** Mini-checkpoint (in its own lesson).

## Key vocabulary per unit

- **Unit 1 (Lessons 1 to 4):** program, output, syntax, error, variable, string, integer, float, input, print, concatenation, type conversion.
- **Unit 2 (Lessons 5 to 8):** condition, if, elif, else, comparison operator, indentation, loop, range, iteration.
- **Unit 3 (Lessons 9 to 12):** list, index, item, append, sequence, testing, debugging.

## Common misconceptions per unit

- **Unit 1:** "The computer reads my code like I do" (it needs exact syntax). Missing quotes around text. Thinking that `=` means "is equal to" as a question. Confusion between `print` and `input`.
- **Unit 2:** Wrong indentation so the code runs the wrong branch. Using `=` instead of `==` in a condition. Assuming `range(5)` includes 5.
- **Unit 3:** Counting list positions from 1 instead of 0. Assuming a list changes when it is printed.
