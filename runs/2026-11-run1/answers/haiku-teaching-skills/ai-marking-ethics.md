# Staff guidance: using AI tools with student essays

**Short answer:** do not paste student essays into a personal or consumer AI account such as ChatGPT. Use only a tool the school has approved for this purpose, and never paste anything that identifies a student.

## Why

- Student essays are personal data. Consumer account terms and settings vary and can change, so the school should not rely on them.
- AI marks can be wrong and inconsistent. A model may credit a point the essay does not make, miss a fact that is there, or give different marks for the same essay on different runs.
- Marking is a professional judgement. The mark and the comment must come from the teacher.

## What is allowed

1. Only school-approved tools, where the school has checked the data terms and has an agreement in place.
2. Remove names, student numbers, class lists and anything about SEND, safeguarding or family circumstances before anything is pasted into an approved tool.
3. After the teacher has decided the mark, an approved tool can help rewrite the teacher's own comment in plainer language. Paste the comment, not the essay.
4. AI can help plan lessons and marking: a model answer, a check of the mark scheme, or a list of common errors to look for.
5. Anything the AI produces is a draft. The teacher reads it and changes it before it goes anywhere.

## What is not allowed

- Pasting full student essays or other student work into a personal account.
- Sending AI marks or AI feedback to a student or parent without the teacher having read and edited it.
- Using an AI detector to decide that a student has cheated. These tools are unreliable and can wrongly accuse students.

## Before any teacher uses a tool to help with marking

- Test it on five essays the teacher has already marked. Compare the tool's marks and comments with the teacher's. If the differences are larger than the school's tolerance, do not use it for marking.
- Record which tool was used and for what, so the school can review it.

## If the school has no approved tool yet

The answer is no for now. Teachers can still use AI for planning and for drafting resources that contain no student work.

## Who to ask

The school's data protection lead or the person responsible for the AI policy should confirm which tools are approved before any teacher starts.
