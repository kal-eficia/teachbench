# Year 3: Column addition with one exchange (one hour, 30 pupils)

**Assumptions:** pupils are secure with adding tens and ones without crossing ten. You have base-10 blocks or drawn place-value counters, a visualiser or board, and a mini-whiteboard for each pair. Pupils already know place value to 100.

## Teacher plan (teacher only)

**Objective:** add two 2-digit numbers using the column method, exchanging 10 ones for 1 ten when the ones total 10 or more.

**Success criteria:** I can line up the tens and ones in columns. I can add the ones and exchange 10 ones for a ten when needed. I can add the tens, including the ten I exchanged.

**Timeline (60 minutes)**

| Time | Segment | Teacher does |
|---|---|---|
| 0 to 5 min | Starter | Recall (student page, Page 1). Take answers on mini-whiteboards. Look at the confidence column, not only the answers. |
| 5 to 8 min | Objective | Say the objective in pupil words. Show 47 + 36 as a sentence: "We are going to add the ones first, and see if we need to swap ten ones for a ten." |
| 8 to 20 min | Model | Build 47 with blocks, then 36 underneath. Add the ones together, aloud. Make 13 ones, exchange 10 for a ten, place 3 ones in the answer, carry 1 ten. Add the tens including the carried ten. Write the column method beside the blocks, one line at a time. Think aloud: "Thirteen is more than ten, so I swap." |
| 20 to 30 min | Guided pairs | Pairs solve 28 + 15 with blocks, then write the column method. Walk round and check the swap happens before the tens are added. |
| 30 to 34 min | Check | Hinge question (student page, Page 3). Pupils show A, B or C on whiteboards. Reteach from the model if fewer than two-thirds choose B. |
| 34 to 49 min | Apply | Independent calculations (Page 4), no blocks for Q4 to Q6. Circulate and use the solutions sheet to check quickly. |
| 49 to 54 min | Share | Show one pupil's correct and one pupil's wrong method. Ask the class which step went wrong. |
| 54 to 57 min | Exit | Exit question (Page 5). |
| 57 to 60 min | Pack away | Pupils collect blocks and whiteboards. |

**Transition lines**
- "Before we start, tell me the answer to 20 + 15."
- "Now the blocks. Watch me count the ones."
- "Your turn with a partner. Swap first, then add the tens."
- "Show me A, B or C."
- "Pick one of the six and try it alone."
- "Show me one answer you're sure about on your slip."

**Misconceptions to listen for**
1. **Writing the 13 in the answer instead of the 3.** Fix: "Thirteen ones is one ten and three ones. Only the three goes in the ones column."
2. **Forgetting the carried ten in the tens column.** Fix: have pupils say "carry" out loud, then add it first before the other tens.
3. **Misaligned columns** (for example 36 written with the 6 under the tens). Fix: draw the columns with a line and mark the tens and ones headings.

**Differentiation**
- Support: keep the blocks on the desk for every question. Use the counter-drawing grid.
- Stretch: 56 + 67 (answer 123), which needs an exchange in the tens column too.

**Notes for next lesson's starter:** check which pupils still write the carried ten in the wrong column, and open next lesson with two questions that use exchange.

## Student page (pupils)

### Page 1: Warm up

Answer these in your head. Write the answer on your whiteboard, then tick a box for how sure you feel.

1. 34 + 20 =
2. 52 + 6 =
3. 40 + 35 =
4. 23 + 14 =

Confidence: Guessing / Think so / Certain

*Summary for the class chat: "I can add tens and ones. My score: __ out of 4."*

### Page 2: Learn

Look at 47 + 36.

Step 1: Write the numbers in columns. Tens go under tens, ones go under ones.

Step 2: Add the ones. 7 + 6 = 13.

Step 3: Thirteen is more than ten. Swap 10 ones for 1 ten. Write the 3 in the ones column. Write a small 1 under the tens column.

Step 4: Add the tens, including the small 1. 4 + 3 + 1 = 8.

Step 5: The answer is 83.

Try it with blocks first if you need to. Then write each step.

*Summary for the class chat: "The swap happens when the ones make ten or more. My answer to 47 + 36 is 83."*

### Page 3: Check

What is 38 + 25?

A. 53
B. 63
C. 513

Show your choice to your teacher on your whiteboard.

*Summary for the class chat: "My answer to 38 + 25 is __."*

### Page 4: Apply

Work out each one using the column method. Write the swap in the column.

1. 28 + 15 =
2. 52 + 21 =
3. 34 + 49 =
4. 46 + 38 =
5. 19 + 33 =
6. 57 + 24 =
7. Mia reads 29 pages on Monday and 18 pages on Tuesday. How many pages does she read altogether?

*Summary for the class chat: "The question I found hardest was number __ because __."*

### Page 5: Exit

Answer this on your slip and hand it in.

65 + 27 = ?

Did you need to exchange? Yes / No

*Summary for the class chat: "My answer is __. I did / did not need to exchange."*

| Page 3 | B (63) | 1 mark. A (53) means the carried ten was forgotten. C (513) means the whole 13 was written in the answer. |

| Page 4 Q7 | 47 | 1 mark for 47. Also award 1 mark for showing the swap in the ones column. |
| Page 5 | 92, Yes | 1 mark for 92. 1 mark for "Yes" with a reason. |
| Homework 1 to 6 | 42, 62, 63, 82, 75, 92 | 1 mark each. |
| Homework 7 | C (62) | 1 mark. |
| Homework 8 | 123 | 1 mark for 123, 1 mark for the sentence explaining both exchanges. |

**Common answers that do not get the mark:** a correct answer with no column method shown still earns the answer mark, but not the method mark on Q7. A 3-digit answer to any 2-digit sum in Q1 to Q6 is incorrect.
