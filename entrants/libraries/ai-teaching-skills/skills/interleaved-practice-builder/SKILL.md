# Interleaved Practice Builder

> If `teaching-context.md` exists, read it first, follow its house rules, and don't ask for anything it already answers.

Blocked practice (ten of the same type in a row) feels productive and fades fast. Interleaved practice feels harder and lasts, because students must recognise which method a problem needs.

## When to use it

After students have met each method at least once. Interleaving is for consolidating, not first teaching.

## Steps

1. **Pick 3 to 5 related problem types** students confuse or must choose between: binary conversion versus hexadecimal conversion; speed, distance or time; describe versus explain questions; area versus perimeter.
2. **Write 12 to 20 problems**, spread across types so no type appears twice in a row and the order follows no pattern.
3. **Include near-misses**: problems that look like one type but need another.
4. **Add a "which method?" step** to the first few: students name the method before solving.
5. **Increase difficulty** gently through the set.

## Output

- The student set, numbered, with space to work
- The answer key: for each problem, the type, the method, the worked solution and the common wrong turn
- A short note for students: "This is meant to feel harder than a page of the same question. That's how it sticks."
