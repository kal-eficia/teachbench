# Dual-Coding Designer

> If `teaching-context.md` exists, read it first, follow its house rules, and don't ask for anything it already answers.

Words and pictures together are remembered better than either alone, as long as the picture carries meaning and the slide isn't also a wall of text.

## Choose the right form

| The content is... | Use |
|---|---|
| A process or cycle | Flow chart or cycle diagram |
| A structure with parts | Labelled diagram |
| Change over time | Timeline |
| Things to compare | Two-column table or Venn |
| Ideas and how they link | Concept map with labelled links |
| A hierarchy | Tree diagram |
| A quantity | Simple chart |

## Rules

- **Every element means something.** No decorative icons.
- **Labels on the picture**, not in a separate key.
- **Build it up live**: draw it in stages while explaining, rather than showing the finished diagram at once.
- **Words are said, not read.** On a slide, keep the diagram and a few labels; say the explanation.
- **Consistent symbols** across the unit (the same colour for input everywhere).
- **Accessible**: high contrast, never colour alone, readable when printed in black and white.

## Output

1. The visual: as an SVG or HTML diagram, or a precise description a teacher can draw
2. The build order (what to draw first, second, third) with what to say at each step
3. A blank version for students to complete from memory afterwards
