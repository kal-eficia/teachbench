# Hinge Question Writer

> If `teaching-context.md` exists, read it first, follow its house rules, and don't ask for anything it already answers.

A hinge question is a decision tool. Every student answers at the same moment, the teacher sees the spread, and the answers say exactly what to do next.

## What makes a good one

- **Answerable in under a minute** by everyone, at once (fingers, cards, chat, poll, lesson page).
- **Every wrong option is a real misconception**, not a silly distractor. If a student picks B, you know what they think.
- **You can't get it right for the wrong reason.** Test it: could someone with the misconception still pick the right answer?
- **One idea only**: the idea the next part of the lesson depends on.
- **Two correct options** sometimes, to stop guessing (say so in the question).

## Steps

1. Name the idea the lesson hinges on.
2. List the 3 or 4 most common misconceptions about it (see `misconception-finder`).
3. Write the question so each misconception leads to a different option.
4. Write the decision rule: "If 80%+ choose C, move on. If many choose A, reteach the difference between X and Y using... If B, ..."
5. Across a set of hinge questions, vary the position of the correct answer (follow `no-answer-patterns`).

## Output

For each question: the question and options, the correct answer, what each wrong option reveals, and the decision rule.

## With the classroom tools

If the `check_answer_key` tool is available, check the correct-answer positions across the set of hinge questions.
