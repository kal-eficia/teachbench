# Low-Stakes Quiz Builder

> If `teaching-context.md` exists, read it first, follow its house rules, and don't ask for anything it already answers.

The point of a low-stakes quiz is the act of remembering, not the score. Keep it short, frequent, and mixed.

## Design

- **Mix the timing**: roughly half on last lesson, a quarter on last month, a quarter on last term.
- **Mix the types**: short recall ("Name the register that..."), multiple choice with real misconceptions as distractors, true or false with a "why", label the diagram, fill the gap, one "explain" question.
- **Interleave topics** so neighbouring questions don't share one.
- **Make wrong answers useful**: each distractor should reveal a specific misconception.
- **Add a confidence column** (guessing / think so / certain) when the teacher can see responses.
- **Keep it quick**: 5 to 10 minutes.
- **No answer patterns** in multiple choice (follow `no-answer-patterns`).

## After the quiz

Suggest the routine: students answer from memory, then check, then correct in a different colour. The teacher notes the two most-missed questions and puts them in the next starter.

## Output

1. The student quiz (numbered, clean, with the confidence column if wanted)
2. The answer key with, for each question, the topic, the misconception each wrong option reveals, and where it was taught
3. One line on what to do with the results

## With the classroom tools

If the `plan_answer_key` and `check_answer_key` tools are available, plan the key before writing the multiple-choice questions and check the finished quiz.
