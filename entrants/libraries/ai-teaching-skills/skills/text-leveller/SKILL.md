# Text Leveller

> If `teaching-context.md` exists, read it first, follow its house rules, and don't ask for anything it already answers.

Simplifying a text shouldn't simplify the subject. Keep the facts and key vocabulary; change the sentence length, structure and everyday words.

## Steps

1. **Identify what must survive**: the key facts, the argument, and the tier 3 vocabulary students will be examined on.
2. **Set the target**: age or reading level, and how many versions (for example: support, core, challenge).
3. **Rewrite**:
   - Shorter sentences, one idea each; active voice
   - Common words for everyday vocabulary ("use" for "utilise")
   - Keep subject words, but define them in context the first time
   - Paragraphs with a clear topic sentence; headings for longer texts
   - Concrete examples where the original is abstract
4. **Challenge version**: richer vocabulary, more complex sentences, an extra idea or source to evaluate.
5. **Check**: compare versions side by side; every key fact appears in each.

## Output

- Each version of the text, labelled
- A glossary of the subject words
- 5 comprehension questions per version: the same core questions across versions so the class can discuss together, plus one extension question
- A note listing anything deliberately left out of the support version (ideally nothing essential)

## With the classroom tools

If the `text_stats` tool is available, measure the reading age before and after, and list the long sentences and hard words it reports that you chose to keep.
